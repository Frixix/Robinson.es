                producto_id (FK)
                cliente_id (FK)
                tipo_movimiento
                cantidad
                fecha

Solven

Aplicación web personal para llevar el control de ingresos, gastos, balance, categorías y resúmenes financieros. Desarrollada por fases como parte de mi aprendizaje en desarrollo web.

Funcionalidades actuales (MVP)

  • Registro de ingresos y gastos con categorías dinámicas
  • Eliminación y edición de transacciones
  • Cálculo automático de ingresos, gastos y balance general
  • Persistencia de datos con LocalStorage
  • Formato de moneda en pesos colombianos (COP)
  • Fecha y hora automática con orden por más reciente
  • Filtros por tipo, categoría y descripción

Hoja de ruta

                Fase 1 · Actual  →  HTML + CSS + JavaScript + LocalStorage
                Fase 2           →  IndexedDB
                Fase 3           →  React
                Fase 4           →  Supabase + Autenticación + Nube
