Inventario 2.0

Sistema de gestión de inventario desarrollado en Python con interfaz Tkinter y base de datos SQLite.

Características

  • Registro de productos
  • Control de stock
  • Movimientos de entrada y salida
  • Historial de inventario

Modelo de base de datos

        PRODUCTOS
        ---------
        id (PK)
        codigo
        nombre
        precio_venta
        stock_actual
        stock_minimo

        MOVIMIENTOS
        -----------
        producto_id (FK)
        cliente_id (FK)
        tipo_movimiento
        cantidad
        fecha
