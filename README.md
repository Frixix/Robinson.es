# Robinson.es

Portafolio personal desarrollado para presentar el perfil profesional de Robinson Rodriguez, su experiencia, formación, habilidades y proyectos.

## Sitio web

Accede al portafolio aquí:
https://frixix.github.io/Robinson.es/

## Descripción

`Robinson.es` es un portafolio web estático construido con HTML, CSS y JavaScript. El sitio incluye:

- Sección de presentación personal
- Información de contacto
- Resumen académico y profesional
- Habilidades técnicas y blandas
- Galería de proyectos
- Modal de detalle para el proyecto principal

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Cómo abrirlo localmente

Al ser un sitio estático, basta con abrir `index.html` en el navegador.

Si prefieres trabajar con servidor local, puedes usar por ejemplo:

```powershell
npx serve .
```
